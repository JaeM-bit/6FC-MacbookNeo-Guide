Setting up the MacBook Neo (Nina) for College

Choose one of the topics below.

MacBook & Microsoft 365

If by MacBook Neo you mean the new MacBook model, Microsoft 365 applications can be installed normally on it. Microsoft 365 supports current Macs, including Apple-silicon Macs.

The main point is the type of student Microsoft 365 licence provided by the school or college. Some education licences provide only browser versions of Word, Excel and PowerPoint, while others include the full desktop applications.

To install Microsoft 365, sign in at Microsoft 365 using the student's college email address, look for Install apps, download the Microsoft 365 installer, install it, then open Word or Excel and sign in again with the student account to activate it.

If there is no Install apps option, the student may have a web-only licence.

Salisbury 6th Form College Compatibility

Salisbury 6th Form College's current BYOD guidance says that students are provided with free Google Workspace and do not need to purchase Microsoft Office.

The college also states that it does not recommend Apple laptops or iPads because they are not fully compatible with all college software.

For most students, the college recommends a Chromebook, while some specialist subjects are better suited to Windows laptops.

This does not mean a MacBook cannot be used, but it is worth checking whether the student's subjects require any Windows-only software.

Biology, Psychology & Physical Education

For Biology, Psychology and A-level Physical Education, there is no obvious subject-specific reason why a MacBook would be unsuitable.

The specialist computer requirements highlighted by S6C mainly concern subjects such as Software Design & Development, Photography and Media. Biology, Psychology and PE are not listed among those specialist requirements.

For these three subjects, most work is likely to involve documents, presentations, research, spreadsheets, PDFs and online college systems, all of which a MacBook handles well.

So although S6C has a general preference against Apple laptops, a MacBook should be a reasonable choice for this particular subject combination.

It is still worth confirming whether the student's account includes a Microsoft 365 desktop licence, because the college currently emphasises Google Workspace rather than Microsoft Office.

Microsoft 365 Installation Steps

  1. On the MacBook, open Safari and go to m365.cloud.microsoft/apps.
  2. Click Sign in.
  3. Sign in using the student's Salisbury 6th Form College email address and password, rather than a personal Microsoft account.
  4. Once signed in, look for Install apps.
  5. Select Microsoft 365 apps.
  6. The Microsoft 365 installer package should download to the Mac.
  7. Open the downloaded .pkg installer and follow the on-screen instructions.
  8. When installation is complete, open Word or Excel from the Applications folder.
  9. When prompted, sign in again with the student's college account to activate Microsoft 365.

If “Install apps” is not shown: the S6C student account may not include a licence for the desktop versions of Word, Excel and PowerPoint. The student can still use the college-provided Google Workspace and, depending on the Microsoft account entitlement, Microsoft web applications.
